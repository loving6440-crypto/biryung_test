# 秘靈 · 비령 전투와 개척 (독립 체험판)

**원본:** 비령 vC.05 (사용자가 제공한 `biryeong_vC.05 (1).zip`)

## 수정 이력: 초기화 후 이전 체력 복원 오류 (2026-11-17 · 수정 2)

- **원인:** 초기화에서 localStorage 데이터를 삭제해도 기존 React 실습 코어가 `pagehide` 및 저장 타이머에서 이전 HP·소지품·진척을 다시 저장할 수 있었습니다.
- **수정:** 초기화 버튼을 누르는 즉시 코어의 저장 함수를 잠그고, `sessionStorage`에 일회성 초기화 표시를 저장합니다. 다음 페이지의 bootstrap은 이 표시를 확인해서 그 사이에 다시 기록된 과거 캐릭터 정보까지 삭제하고 육조 3인 신규 샘플을 생성합니다.
- 연속 탐색을 피하도록 초기화 시 주소는 `#/battle`로 정리하고 전체 페이지 새로고침을 한 번만 실행합니다.
- 이전 전투·소지품·개척 기록이 사라지는 것은 의도된 초기화 동작이며, 본편 비령의 저장소에는 영향을 주지 않습니다.
- 저장 데이터 재기록을 재현한 회귀 테스트를 추가하여 총 8개 테스트가 통과했습니다. 실제 브라우저 클릭 테스트는 실행 환경의 접근 제한으로 수행하지 못했습니다.

GitHub Actions에 이미 배포했다면 `public/bootstrap.js`, `public/play/play.js`, `public/standalone.js`, `public/index.html` 네 파일을 이 수정본으로 덮어쓰고 커밋하세요. Pages의 소스가 **GitHub Actions**인지 확인하세요.
직접 배포 방식이면 별도 정적 ZIP의 최상위 파일들을 덮어쓰고 커밋하세요.

이미 열린 페이지라면 `Ctrl+Shift+R`로 강력 새로고침하세요.

## 무엇이 들어 있나

- **전투:** 원본 퇴마 실습 화면의 전투 안내(4단계 튜토리얼), 1인 전투 3종(허수아비 잡귀 / 먹구렁이 / 묵은 원귀)
- **개척:** 뒷산 10×10 개척 맵의 산길 1, 2, 3, 4
- **샘플 캐릭터:** 비령 견습생, 17세, 육조(안목/호전/인내/절제/신속/이해) 모두 3, 초기 체력·의지력 100
- 비령 vC.05의 전투·개척 계산/화면, 비령 스타일시트, 도트 화면 자산 유지
- **로그인, DB 설정, Supabase, Render 백엔드 불필요**

## 실행하기

Node.js 20 이상이 있으면:

```bash
npm run dev
```

그런 다음 `http://localhost:4173`으로 접속합니다. **npm install은 필요하지 않습니다.** 파일을 직접 더블클릭해서 `file://`로 여는 대신 로컬 서버 또는 정적 호스팅을 사용하세요.

## 배포용 빌드

```bash
npm run build
```

생성된 **`dist/` 폴더의 내용**을 Netlify, GitHub Pages, Cloudflare Pages 등의 정적 호스팅에 올리면 됩니다. Netlify에서는 Build command = `npm run build`, Publish directory = `dist`로 설정하세요.

`public/` 자체도 정적 파일로 배포할 수 있지만, 권장 배포 방식은 `dist/`입니다.

## 저장 및 독립성

- 체험판 기록은 브라우저 `localStorage`의 `biryeong-battle-pioneer-demo-v1` 하나에 저장됩니다.
- **기존 비령 계정·원본 게임 서버와 완전히 별개**이며 원본 데이터를 읽거나 변경하지 않습니다.
- 페이지 오른쪽의 **초기화** 버튼으로 체험판 기록만 지울 수 있습니다.
- 샘플 캐릭터 기본 스탯은 언제나 3으로 유지됩니다. 다만 원본 규칙의 `쇠약`처럼 일시적인 스탯 감소가 전투·개척 계산에 반영될 수 있습니다.
- 전투/개척 보상, 소지품, 전투 기록 등은 로컬에서만 작동합니다. 다른 기기와 동기화되지 않습니다.

## 구성

```text
public/
  index.html             비령 스타일의 독립 홈페이지
  bootstrap.js           샘플 프로필 및 계정 대신 로컬 저장 연결
  standalone.js          메뉴, 전환, 프로필, 상태, 소지품, 초기화
  standalone.css         체험판 레이아웃
  styles.css             원본 비령 vC.05 디자인
  assets/                원본 비령 화면 이미지
  play/play.js           원본 비령 vC.05 게임 번들 기반, 메뉴 범위 제한
  play/play.css          원본 비령 전투·개척 스타일
scripts/build.mjs        외부 패키지 없이 dist 생성
scripts/serve.mjs        로컬 개발용 서버
```

`play/play.js`는 원본에 이미 빌드되어 포함된 React 게임 코어를 사용합니다. 원본 동작을 유지하며, 표시되는 **1인 전투 목록을 3종으로, 개척 선택 목록을 산길 1~4로 제한**했습니다. 무관한 원본 메뉴는 독립 홈페이지에 연결하지 않습니다. 원본 번들에 비활성 모듈 데이터가 일부 남아 있을 수 있으나 서버 요청·로그인 기능은 실행하지 않습니다.

> 별도의 서버 저장이 없으므로 캐릭터 진척도가 브라우저를 바꾸면 이전되지 않습니다. 의도된 데모 동작입니다.
