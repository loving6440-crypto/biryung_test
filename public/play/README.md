# 비령 vC.05 게임 코어 (독립 체험판)

`play.js`는 첨부된 비령 vC.05의 빌드 결과를 재사용한 파일입니다.
원본 실습 UI·전투/개척 규칙·효과를 유지하면서 화면에 나타나는 전투 상대는
`scarecrow`, `snake`, `wonhon` 세 종류로, 개척 터 목록은
`left-trail-1`부터 `left-trail-4`까지로 제한하였습니다.

이 파일은 완성된 번들이므로 이 체험판에서 `npm run build`를 실행하면
React 등을 다시 컴파일하지 않고 정적 홈페이지와 함께 `dist/`로 복사합니다.
전체 비령 게임을 재빌드하거나 서버 코드를 가져오지 않습니다.
